# Bahia Digital

Site institucional simples para a empresa "Bahia Digital" — uma agência/empresa que oferece serviços de tecnologia, desenvolvimento de sites, sistemas web, aplicativos, suporte e segurança da informação.

## Descrição

Este repositório contém uma landing page estática construída com HTML e CSS. O objetivo é apresentar os serviços, projetos e formas de contato da Bahia Digital.

## Visualização

Abra o arquivo `index.html` no seu navegador para visualizar o site localmente.

## Tecnologias

- HTML5
- CSS3

## Como executar localmente

1. Clone o repositório:

   git clone https://github.com/Vitor6467/bahia-digital.git

2. Acesse a pasta do projeto:

   cd bahia-digital

3. Abra `index.html` diretamente no navegador ou rode um servidor HTTP simples (recomendado):

   - Com Python 3:

     python -m http.server 8000

     Depois abra http://localhost:8000

   - Com http-server (Node.js):

     npx http-server

     Depois abra o endereço exibido pelo comando.

## Estrutura do projeto

- `index.html` — página principal
- `style.css` — estilos do site

## Deploy (GitHub Pages)

1. Vá para as configurações do repositório no GitHub.
2. Na seção "Pages", selecione a branch `main` e a pasta `/ (root)` como origem.
3. Salve. O site estará disponível em `https://Vitor6467.github.io/bahia-digital/` assim que feito o deploy.
